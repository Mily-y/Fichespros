# FichesPro — Fiches pédagogiques Bénin

Plateforme de fiches pédagogiques pour enseignants et apprenants au Bénin.

## 🚀 Déploiement

### 1. Installation locale
```bash
npm install
npm run dev
```
Ouvrir http://localhost:3000

### 2. Déploiement Vercel
```bash
git init
git add .
git commit -m "FichesPro v1.0"
git remote add origin https://github.com/TON-PSEUDO/fichespro.git
git push -u origin main
```
Puis connecter le repo sur vercel.com.
